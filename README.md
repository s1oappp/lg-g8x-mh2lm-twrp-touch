# LG G8X `mh2lm` — TWRP with working touch

Техническая документация о проверенной конфигурации TWRP 3.7.1_12-0 для
LG G8X ThinQ (`LMG850EMW`, `mh2lm`), в которой пользователь подтвердил работу
сенсора после обычной перезагрузки.

## Проверенная конфигурация

- TWRP: `3.7.1_12-0`
- kernel: `4.14.340-openela-perf+`
- recovery image SHA-256:
  `b31b0cd4b8ec417bedefec020d5f2216295ba4d9ae67ed9296f43beece6305d3`
- установленный target: `boot_b`
- активный слот при последней read-only проверке: `b`
- используемый DTBO: исходный `dtbo_b`, не менялся; наблюдался
  `androidboot.dtbo_idx=5`
- сохранённая RAM event-трасса содержит `BTN_TOUCH` и мультитач X/Y events.

Рабочий результат относится к сочетанию образа с B/DTBO B. Тот же образ при
тесте с A/`dtbo_idx=3` не регистрировал `touch_dev`; первопричина различия
окончательно не установлена.

## Восстановление точного образа

Рабочий `.img` намеренно не входит в этот публичный репозиторий. Его точная
исходная сборка и права на публичное распространение не установлены; также не
публикуются boot/DTBO backups или ROM images. В runbook описан точный
воспроизводимый способ получить тот же SHA-256 из donor-файла
`twrp-normal-mode.img`, если он у вас есть.

В репозитории есть проверяющий helper:

```sh
python3 tools/rebuild_candidate.py /path/to/twrp-normal-mode.img \
  /path/to/new-output.img
```

Helper проверяет SHA-256 donor, структуру boot header, изменяет только
`androidboot.mode=normal` и boot image ID и отказывается перезаписывать
существующий выходной файл. Ожидаемый результат:

```text
size:   47796224
sha256: b31b0cd4b8ec417bedefec020d5f2216295ba4d9ae67ed9296f43beece6305d3
```

Если отсутствуют и рабочий образ, и donor `twrp-normal-mode.img`, опубликованных
сведений недостаточно для гарантированного пересоздания kernel+ramdisk из
исходников: точный manifest, commit и build provenance не сохранены. Не
подменяйте их произвольной сборкой.

## Безопасность и лицензирование

- Этот репозиторий содержит документацию и host-side rebuild helper, но не
  recovery image, ROM, partition dump или firmware.
- Для дальнейшей проверки на телефоне используйте только описанный RAM-only
  `fastboot boot`. Не используйте `fastboot flash`, `fastboot set_active` или
  установочные ZIP в рамках этой процедуры.
- Видимость репозитория — public. Лицензия пока не задана: происхождение
  некоторых исходных бинарных компонентов не установлено, а публичная
  видимость сама по себе не предоставляет прав на их распространение.
